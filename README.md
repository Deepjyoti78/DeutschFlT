> **"Learn German, Open Opportunities in Europe."**  
> An editorial, high-end European coaching website founded by **Utkal Das**, tailored for ambitious learners preparing for Goethe-Institut, ÖSD, TestDaF, and relocation across Germany and Europe.

---

## 🇩🇪 Features

- **Master Visual Identity**: Warm cream backgrounds (`#FBF8F5`, `#F6F5EC`), deep forest green (`#174D2A`), olive accents (`#91AC32`), and sophisticated serif typography (*Playfair Display* & *DM Sans*).
- **100% Fully Mobile Responsive**: Tested across 375px mobile, tablet, and 1440px desktop resolutions with zero layout shifts or horizontal overflows.
- **Fluid Micro-Interactions**: Smooth entrance animations, scroll reveals, and staggered card transitions with Framer Motion.
- **13 Complete Sections**:
  1. **Sticky Header & Mobile Drawer** with quick booking triggers
  2. **Editorial Hero Section** with student visual and certification badges
  3. **Trust & Standards Strip** (Goethe-Institut, ÖSD, TestDaF, German Universities, CEFR)
  4. **Why Learn with Us?** (Personalized Coaching, Career & Study Guidance, Exam Preparation)
  5. **Before / After Transformation** (Vorher vs Nachher comparison cards)
  6. **Meet the Founder** (Utkal Das profile, speaking specialization & credentials)
  7. **Target Audience** (Speaking, Vocabulary, Career, Growth)
  8. **Platform Features** (8 structured cards)
  9. **How It Works** (From Hallo to Zertifikat - 5 step roadmap)
  10. **Curriculum Courses** (Foundation A1–A2, Intermediate B1–B2 [Popular], Advanced C1–C2)
  11. **Interactive Pricing Grid** (All 12 modules from A1.1 to C2.2 with level selector filters)
  12. **Interactive FAQ Accordion** (8 detailed answers)
  13. **Contact Section & Booking** with React Hook Form + Zod validation
  14. **Deep Forest Green Footer** with 4 link columns & legal notes

---

## 🛠 Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & CSS Variables
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Validation**: React Hook Form + Zod

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Deepjyoti78/DeutschFIT.git
   cd DeutschFIT
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   npm run start
   ```
